## Processing Approach

The solution processes the supplied financial datasets locally using deterministic Python logic.

The workflow includes:

- Financial profile reconstruction
- Financial event cleaning
- Settlement-date based cash-flow forecasting
- Recurring transaction detection
- Future recurring transaction generation
- Currency conversion using supplied exchange-rate data
- Safe amount calculation
- Earliest full-payment calculation
- Payment-plan validation
- Flexible spending-change validation
- Deterministic decision generation

No model inference or external model API calls are used during the final dataset run that generates `output.csv`.

## Reproducibility

The final `output.csv` is generated by running the solution locally against:

- `dataset/requests.csv`

- Other supplied dataset files required by the workflow

The same inputs and code produce deterministic results.
